Skaičių aibės — pavyzdžiai ir savikontrolė

Matematika · 11 klasė · B kursas · 1 skyrius „Skaičiai ir skaičiavimai I" · 1.1 tema

I DALISIšspręsti pavyzdžiai
1 Aibių skirtumas
Duota: A = {1; 2; 3; 4; 5; 6}, B = {4; 5; 6; 7; 8; 9}.
Raskite B ∖ A.
B ∖ A — elementai, kurie priklauso B, bet nepriklauso A: B ∖ A = {7; 8; 9}
2 Aibė pagal savybę — dalikliai
Duota: aibė N — skaičiaus 10 natūralieji dalikliai, aibė K — skaičiaus 12 natūralieji dalikliai. M = N ∩ K.
Kiek elementų turi aibė M?
N = {1; 2; 5; 10}    K = {1; 2; 3; 4; 6; 12}
M = N ∩ K = {1; 2}  ⇒  2 elementai
3 Žodinis uždavinys — įtraukimas–atmetimas
Taisyklė: |A∪B| = |A| + |B| − |A∩B|.
Visi klasės mokiniai sportuoja: kiekvienas lanko bent vieną iš dviejų būrelių. Krepšinį lanko 18 mokinių, futbolą — 12 mokinių, o 2 mokiniai lanko abu būrelius. Kiek iš viso mokinių yra klasėje?
Iš viso mokinių: 18 + 12 − 2 = 28 mokiniai
4 Trys baigtinės aibės
Duota: A = {2; 4; 8; 19}, B = {4; 8; 12; 13}, C = {12; 13; 19; 24}.
Raskite A ∩ B ir B ∪ C.
A ∩ B = {4; 8}    B ∪ C = {4; 8; 12; 13; 19; 24} (bendri 12, 13 skaičiuojami tik kartą)
5 Intervalai kaip aibės
Duota: A = [−15; 0), B = [−6; 6).
Raskite A ∪ B ir A ∩ B.
A ∪ B — kadangi intervalai persidengia, sąjunga yra vienas intervalas nuo mažiausios iki didžiausios ribos: A ∪ B = [−15; 6)
A ∩ B — imame siauresnes ribas: A ∩ B = [−6; 0)
II DALISSavikontrolė
? Išspręsk savarankiškai, paskui pasitikrink atsakymus
Nurodymas: kiekvienam uždaviniui užrašyk sprendimą, tada palygink su atsakymu lapo apačioje.
Baigtinės aibės — sąjunga, sankirta, skirtumas
  1. A = {1; 2; 4; 6}, B = {4; 5; 6; 9}. Raskite B ∩ A.
  2. A = {3; 4; 5}, B = {2; 4; 6}. Raskite A ∪ B.
  3. A = {1; 2; 3; 4; 5}, B = {1; 3; 5}. Raskite |A ∖ B|.
Baigtinės aibės — daugiau elementų
  1. A = {3; 5; 9; 13}, B = {3; 6; 9; 13; 16}. Raskite A ∩ B ir A ∪ B.
  2. A = {−3; −2; −1; 0; 1; 3; 4}, B = {−5; −3; −1; 3; 5}. Raskite |A ∩ B|.
  3. A = {2; 3; 5; 7; 9; 11}, B = {1; 3; 5; 7; 9; 10}. Raskite |A ∪ B|.
  4. A = {1; 5; 8; 9; 14; 19; 20}, B = {1; 5; 7; 9; 12; 20}. Raskite |A ∩ B|.
  5. A = {0; 1; 2; 3; 5; 7; 8; 9}, B = {1; 2; 7; 8; 9; 10}. Raskite C = A ∪ B.
Aibė pagal savybę / poaibiai
  1. A = {−5; −4; 3; 7; 9}, B = {3; 5; 7; 9; 13}. a) Raskite A ∩ B. b) Kiek daugiausiai elementų gali turėti aibės A poaibis, sudarytas vien iš nelyginių skaičių?
Intervalai
  1. Raskite (−7; 4] ∩ [−1; 5).
  2. A = [−2; 4), B = (−6; 3]. Raskite A ∩ B.
  3. A = [1; 3], B = [2; 6). Raskite A ∩ B.
  4. A = (−2; 3), B = (2; 5). Raskite A ∪ B.
Intervalai — pasirink teisingą atsakymą
  1. A = {−5; −1; 0; 2; 3; 5; 7}, B = {−5; −2; 0; 1; 7; 9}. Raskite |A ∪ B|.
    A. 3    B. 7    C. 10    D. 13

    A. (−2; 1)    B. (−2; 1]    C. (−∞; 1)    D. (−∞; 1]

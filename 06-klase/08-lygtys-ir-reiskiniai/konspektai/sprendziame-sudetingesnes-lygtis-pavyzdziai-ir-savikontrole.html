Sprendžiame sudėtingesnes lygtis — pavyzdžiai ir savikontrolė

Matematika · 6 klasė · 8.2.2 tema · narių perkėlimas ir panašiųjų narių sutraukimas

I DALISIšspręsti pavyzdžiai
1 Narių perkėlimas
Taisyklė: narį perkeliame į kitą pusę pakeisdami jo ženklą; gale dalijame iš skaičiaus prieš x.
3x + 2 = 8
3x = 8 − 2 = 6  →  x = 6 : 3 = 2
4 − 7x = −3
−7x = −3 − 4 = −7  →  x = −7 : (−7) = 1  ((−) : (−) = +)
2 Panašiųjų narių sutraukimas
Taisyklė: sutraukiame narius su ta pačia raidine dalimi — sudedame jų koeficientus.
4x − 7x = −6
−3x = −6  →  x = −6 : (−3) = 2
−9x + 4x = −4
−5x = −4  →  x = −4 : (−5) = 0,8
3 Kai nežinomasis yra abiejose pusėse
Taisyklė: narius su x perkeliame į vieną pusę, skaičius — į kitą, tada sutraukiame ir dalijame.
3x = x − 8
3x − x = −8  →  2x = −8  →  x = −4
−6x + 5 = 3 − 2x
−6x + 2x = 3 − 5  →  −4x = −2  →  x = 12  (= 0,5)
4 Lygtys su dešimtainiais skaičiais
Taisyklė: su dešimtainiais elgiamės taip pat — perkeliame, sutraukiame ir dalijame.
1,8x − 2,4 = 6,6
1,8x = 6,6 + 2,4 = 9  →  x = 9 : 1,8 = 5
0,7x − 3,4x = 2,7
−2,7x = 2,7  →  x = 2,7 : (−2,7) = −1
II DALISSavikontrolė
? Išspręsk savarankiškai, paskui pasitikrink atsakymus
Nurodymas: perkelk narius keisdamas ženklą; nežinomuosius suk į vieną pusę, skaičius — į kitą; sutrauk panašiuosius ir nepamiršk padalyti iš skaičiaus prieš x. Atsakymus rasi lapo apačioje.
Perkėlimas
  1. 5x + 3 = 18
  2. 7x − 2 = 12
  3. 6 − 4x = 14
  4. 9x + 5 = −13
Panašiųjų narių sutraukimas
  1. 6x − 10x = −8
  2. −5x + 8x = −9
  3. −7x + 2x = −4
  4. 0,5x − 2,5x = 4
Nežinomasis abiejose pusėse
  1. 4x = 20 − x
  2. 6x + 4 = 8x
  3. 2x − 9 = 5x
  4. −5x + 6 = 2 − 3x
Dešimtainiai skaičiai ir dalyba
  1. 2,4x − 1,2 = 3,6
  2. x : 5 − 3 = 1
Taikymas
  1. Su kuria a reikšme reiškinių 4a + 2 ir 6a − 8 reikšmės yra lygios?
  2. Krepšyje raudonų obuolių yra 2 kartus daugiau negu žalių. Iš viso 30 obuolių. Kiek krepšyje žalių obuolių? (Pažymėk žalių obuolių skaičių x.)

Atsakymai

1. x = 3    2. x = 2    3. x = −2    4. x = −2
5. x = 2    6. x = −3    7. x = 0,8    8. x = −2
9. x = 4    10. x = 2    11. x = −3    12. x = 2
13. x = 2    14. x = 20
15. 4a + 2 = 6a − 8 → −2a = −10 → a = 5
16. x + 2x = 30 → 3x = 30 → x = 10 (žalių obuolių)

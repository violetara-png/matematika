Sprendžiame sudėtingesnes lygtis

Matematika · 6 klasė · 8.2.2 tema · lygčių sprendimas

Ką išmoksi šioje pamokoje

  1. Kokias lygtis vadiname sudėtingesnėmis
  2. Perkėlimo taisyklė
  3. Panašiųjų narių sutraukimas lygtyje
  4. Kai nežinomasis yra abiejose pusėse
  5. Lygtys su dešimtainiais skaičiais
  6. Dažniausios klaidos

1 Kokias lygtis vadiname sudėtingesnėmis

Sudėtingesnė lygtis — tai lygtis, kurioje nežinomasis x arba skaičiai yra abiejose pusėse, arba tą pačią pusę reikia dar sutvarkyti (sutraukti panašiuosius narius).

Tokias lygtis sprendžiame dviem žingsniais:

  1. perkeliame narius iš vienos pusės į kitą (keisdami ženklą), kad nežinomieji atsidurtų vienoje pusėje, o skaičiai — kitoje;
  2. sutraukiame panašiuosius narius ir dalijame iš koeficiento prie x.

Pavyzdys. −4x + 7 = 6  | − 7
−4x = −1  | : (−4)  →  x = 14

2 Perkėlimo taisyklė

Bet kurį lygties narį galima perkelti iš vienos pusės į kitą, pakeitus jo ženklą priešingu.

a + b = c  →  a = c − b

Taip elgtis leidžia lygties savybė: prie abiejų pusių pridėjus (arba iš abiejų atėmus) tą patį skaičių, lygties sprendinys nepasikeičia. Perkėlimas — tik trumpesnis to užrašymo būdas.

Pavyzdys.
3x + 2 = 8  →  3x = 8 − 2  →  3x = 6  →  x = 2
4 − 7x = −3  →  −7x = −3 − 4  →  −7x = −7  →  x = 1

Dėmesio. Perkeliame tik tada, kai narys pereina per lygybės ženklą. Perkeltas +2 tampa −2, o −7x liktų −7x, jei jo neperkeltume. Ženklą keičia tik tas narys, kuris keliauja į kitą pusę.

3 Panašiųjų narių sutraukimas lygtyje

Panašūs nariai — tai nariai su ta pačia raidine dalimi (pvz. 4x ir −7x). Prieš spręsdami, tokius narius sutraukiame — sudedame jų koeficientus, o raidę paliekame.

4x − 7x = −6  →  −3x = −6  →  x = 2

Pavyzdžiai.
−6x + 8x = −4  →  2x = −4  →  x = −2
−9x + 4x = −4  →  −5x = −4  →  x = 0,8

Dėmesio. Sutraukiame tik tuos narius, kurie turi tą pačią raidę. Skaičius ir narį su x sudėti negalima: 2x + 3 lieka 2x + 3.

4 Kai nežinomasis yra abiejose pusėse

Jei x yra abiejose lygties pusėse, visus narius su x perkeliame į vieną pusę, o skaičius — į kitą, ir sutraukiame.

Pavyzdys. 3x = x − 8
Iš abiejų pusių atimame po x (arba x perkeliame į kairę):
3x − x = −8  →  2x = −8  →  x = −4

Pavyzdys. −6x + 5 = 3 − 2x
Prie abiejų pusių pridedame po 2x:
−6x + 2x + 5 = 3  →  −4x + 5 = 3  | − 5
−4x = −2  | : (−4)  →  x = 12

Patarimas. Narius su x patogu perkelti į tą pusę, kur jų koeficientas didesnis, kad prie x liktų teigiamas skaičius.

5 Lygtys su dešimtainiais skaičiais

Su dešimtainiais skaičiais elgiamės lygiai taip pat: perkeliame narius, sutraukiame panašiuosius ir dalijame iš koeficiento prie x.

Pavyzdžiai.
1,8x − 2,4 = 6,6  →  1,8x = 9  →  x = 5
0,7x − 3,4x = 2,7  →  −2,7x = 2,7  →  x = −1
−0,1x + 2,7 = 2  →  −0,1x = −0,7  →  x = 7

Dėmesio. Dešimtainį skaičių dalijant iš dešimtainio, patogu abu paversti tais pačiais vienetais: 2,7 : (−2,7) = −1, o 9 : 1,8 = 5 (nes 1,8 · 5 = 9).

6 Dažniausios klaidos

KlaidaTeisingai
3x + 2 = 8 → 3x = 8 + 23x = 8 − 2 = 6 (perkeliant keiti ženklą)
−4x = −2 → x = 2x = 12  (−2 : (−4) = 0,5)
2x + 3 = 5x sutraukiam → 5x5x − 2x = 3 → 3x = 3 → x = 1
3x = x − 8 → 3x = −83x − x = −8 → 2x = −8 (x perkeltas keičia ženklą)

Auksinė taisyklė. Perkeldamas narį — keisk ženklą; nežinomuosius suk į vieną pusę, skaičius — į kitą; gale nepamiršk padalyti iš skaičiaus prieš x.

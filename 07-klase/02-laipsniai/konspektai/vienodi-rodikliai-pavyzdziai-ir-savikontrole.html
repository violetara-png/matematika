Laipsniai su vienodais rodikliais — pavyzdžiai ir savikontrolė

Matematika · 7 klasė · Laipsniai · daugyba, dalyba, sandaugos laipsnis

I DALISIšspręsti pavyzdžiai
1 Daugyba: pagrindus sudauginame
Taisyklė: an · bn = (a · b)n. Kai rodikliai vienodi, pagrindus sudauginame, o rodiklį paliekame tą patį.
2⁴ · 3⁴
= (2 · 3)⁴ = 6⁴
2³ · 5³
= (2 · 5)³ = 10³ = 1000
4² · 2²
= (4 · 2)² = 8² = 64
2 Dalyba: pagrindus padaliname
Taisyklė: an : bn = (a : b)n (b ≠ 0). Rodiklis nekinta.
15³ : 5³
= (15 : 5)³ = 3³ = 27
6⁴ : 2⁴
= (6 : 2)⁴ = 3⁴ = 81
12² : 4²
= (12 : 4)² = 3² = 9
3 Sandaugos laipsnis (koeficientas prie kintamojo)
Taisyklė: (a · b)n = an · bn. Koeficientą prie kintamojo kelk tuo pačiu laipsniu.
(3x)⁴
= 3⁴ · x⁴ = 81x⁴
(2a)⁵
= 2⁵ · a⁵ = 32a⁵
(5y)²
= 5² · y² = 25y²
4 Patogus skaičiavimas (gražus rezultatas)
Taisyklė: jei pagrindų sandauga arba dalmuo yra gražus skaičius (1 arba 10), skaičiuoti lengva. Prisimink: 1n = 1.
0,5³ · 2³
= (0,5 · 2)³ = 1³ = 1
0,2² · 5²
= (0,2 · 5)² = 1² = 1
II DALISSavikontrolė
? Išspręsk savarankiškai, paskui pasitikrink atsakymus
Nurodymas: daugyboje pagrindus sudaugink, dalyboje padalink, o rodiklį palik tą patį. Koeficientą prie kintamojo kelk tuo pačiu laipsniu. Atsakymus rasi lapo apačioje.

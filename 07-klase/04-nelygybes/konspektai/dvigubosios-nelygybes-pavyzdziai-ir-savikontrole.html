Dvigubosios nelygybės — pavyzdžiai ir savikontrolė

Matematika · 7 klasė · Nelygybės · dvigubosios nelygybės a < x ≤ b sprendimas, dalijimas iš neigiamo skaičiaus

I DALISIšspręsti pavyzdžiai
1 Dviguboji nelygybė, sistema ir intervalas
Taisyklė: a < x ≤ b reiškia sistemą {x > a; x ≤ b}. Sprendinių aibė — intervalas; galas su ≤ arba ≥ žymimas laužtiniu [ ], su < arba > — apvaliu ( ).
Užrašyk −3 < x ≤ 2 sistema ir intervalu
sistema: {x > −3; x ≤ 2};   galas 2 įeina, −3 neįeina  ⇒  (−3; 2]
Užrašyk 6 < x + 2 < 9 intervalu
iš visų trijų dalių atimam 2: 4 < x < 7  ⇒  (4; 7),  sveikieji 5; 6
2 Sprendimas pertvarkant visas tris dalis
Taisyklė: tą patį veiksmą atliekame iš karto su kaire, vidurine ir dešine dalimis, kol vidurinėje lieka vienas x.
Išspręsk −1 < x + 4 < 0
atimam 4 iš visų dalių: −5 < x < −4  ⇒  (−5; −4)  (sveikųjų nėra)
Išspręsk −6 < x − 4 ≤ −1
pridedam 4 prie visų dalių: −2 < x ≤ 3  ⇒  (−2; 3]
Išspręsk −11 < 3x + 7 ≤ 1
atimam 7: −18 < 3x ≤ −6;  dalinam iš 3: −6 < x ≤ −2  ⇒  (−6; −2]
3 Dalijimas iš neigiamo skaičiaus
Taisyklė: dalijant (ar dauginant) visas tris dalis iš neigiamo skaičiaus, visų nelygybių ženklai keičiasi priešingais, o kraštinės sukeičiamos vietomis.
Išspręsk −4 ≤ 3 − 2x < 1
atimam 3: −7 ≤ −2x < −2;  dalinam iš −2 (ženklai keičiasi): 3,5 ≥ x > 1
sukeičiam kraštines: 1 < x ≤ 3,5  ⇒  (1; 3,5],  sveikieji 2; 3
II DALISSavikontrolė
? Išspręsk savarankiškai, paskui pasitikrink atsakymus
Nurodymas: sprendžiant dvigubąją nelygybę, pertvarkyk visas tris dalis vienodai. Dalijant iš neigiamo skaičiaus — apverk ženklus ir sukeisk kraštines. Skliaustą parink pagal ženklą (≤, ≥ → [ ]; <, > → ( )). Atsakymus rasi lapo apačioje.
A grupė · Užrašyk intervalu
  1. −2 < x ≤ 5
  2. −7 ≤ x < 0
  3. 3 ≤ x ≤ 8
  4. −4 < x < 1
B grupė · Išspręsk ir užrašyk intervalą
  1. 6 < x + 2 < 9
  2. −6 < x − 4 ≤ −1
  3. −4 ≤ 2x < 6
  4. −11 < 3x + 7 ≤ 1
C grupė · Dalijimas iš neigiamo
  1. −4 ≤ 3 − 2x < 1
  2. 1 ≤ 7 − 3x < 10
D grupė · Atsakyk skaičiumi
  1. Didžiausias sveikasis, kai −11 < 3x + 7 ≤ 1?
  2. Mažiausias sveikasis, kai −4 ≤ 2x < 6?
  3. Kiek sveikųjų tenkina −3 < x ≤ 2?
  4. Kiek sveikųjų tenkina 4 < x < 7?

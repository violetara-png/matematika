1 Kas yra dviguboji nelygybė

Dviguboji nelygybė vienu užrašu susieja tris dalis, pavyzdžiui a < x ≤ b. Ji reiškia, kad skaičius x yra didesnis už a ir tuo pačiu mažesnis arba lygus b.

a < x ≤ b   reiškia   x > a  IR  x ≤ b

Vidurinėje dalyje paprastai stovi nežinomasis x, o kraštinės — skaičiai. Ženklai gali būti griežti (<, >) arba negriežti (≤, ≥).

Pavyzdys. −3 < x ≤ 2 reiškia: x didesnis už −3 ir ne didesnis kaip 2. Tokį x atitinka intervalas (−3; 2].

2 Dviguboji nelygybė kaip sistema ir intervalas

Kiekvieną dvigubąją nelygybę galima užrašyti kaip dviejų nelygybių sistemą:

a < x ≤ b   ⇔   { x > a;   x ≤ b }

Sprendinių aibė yra intervalas. Kraštinę žymime laužtiniu skliaustu [ arba ], kai galas įeina (ženklas ≤ arba ≥), ir apvaliu skliaustu ( arba ), kai galas neįeina (ženklas < arba >).

NelygybėSistemaIntervalas
−3 < x ≤ 2{x > −3; x ≤ 2}(−3; 2]
−1 ≤ x ≤ 9{x ≥ −1; x ≤ 9}[−1; 9]
−8 < x < −3{x > −8; x < −3}(−8; −3)
0 ≤ x < 4{x ≥ 0; x < 4}[0; 4)

3 Sprendimas: pertvarkome visas tris dalis

Dvigubąją nelygybę sprendžiame tą patį veiksmą atlikdami iš karto su visomis trimis dalimis — kaire, vidurine ir dešine. Tikslas — vidurinėje dalyje palikti vieną x.

Pavyzdys 1. 6 < x + 2 < 9.

iš visų trijų dalių atimame 2:   6 − 2 < x < 9 − 2 gauname:   4 < x < 7   ⇒   (4; 7) sveikieji sprendiniai:   5; 6

Pavyzdys 2. −11 < 3x + 7 ≤ 1.

atimame 7:   −18 < 3x ≤ −6 dalijame iš 3 (teigiamas — ženklai nesikeičia):   −6 < x ≤ −2 atsakymas:   (−6; −2]

4 Dalijimas iš neigiamo skaičiaus

Svarbiausia taisyklė. Kai visas tris dalis dauginame arba dalijame iš neigiamo skaičiaus, visų nelygybių ženklai keičiasi priešingais, o po to kraštinės sukeičiamos vietomis (mažesnysis skaičius turi likti kairėje).

Pavyzdys. −4 ≤ 3 − 2x < 1.

atimame 3 iš visų dalių:   −7 ≤ −2x < −2 dalijame iš −2 → ženklai keičiasi (≤ tampa ≥, < tampa >):   3,5 ≥ x > 1 sukeičiame kraštines vietomis:   1 < x ≤ 3,5 atsakymas:   (1; 3,5],   sveikieji: 2; 3

Dėmesio. Ženklo pakeitimą darome iš karto visose trijose dalyse. Užmiršus sukeisti kraštines, gaunama „apversta“ nelygybė 3,5 ≥ x > 1 — ji teisinga, bet įprasta ją perrašyti tvarkinga forma 1 < x ≤ 3,5.

Auksinė taisyklė. Sprendi visas tris dalis kartu; dalijant iš neigiamo — apverk ženklus ir sukeisk kraštines. Atsakymą užrašyk intervalu, o skliaustą parink pagal ženklą: ≤, ≥ → [ ],  <, > → ( ).

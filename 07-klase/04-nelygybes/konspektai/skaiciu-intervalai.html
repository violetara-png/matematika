1 Atviras ir uždaras intervalas

Skaičių intervalas — tai visi skaičių tiesės skaičiai, esantys tarp dviejų galų. Nelygybę su x galima trumpai užrašyti intervalu.

Jei galai NEįeina (griežtoji nelygybė <), intervalas vadinamas atviru ir žymimas apvaliais skliaustais. Tiesėje galai piešiami tuščiaviduriais (baltais) taškais.

−2 < x < 5  →  (−2; 5)

Jei galai įeina (negriežtoji nelygybė ≤), intervalas vadinamas uždaru ir žymimas laužtiniais skliaustais. Tiesėje galai piešiami pilnaviduriais (užpildytais) taškais.

−2 ≤ x ≤ 5  →  [−2; 5]

Atmink. Apvalus skliaustas ( ) — galas neįeina (tuščiaviduris taškas). Laužtinis skliaustas [ ] — galas įeina (pilnaviduris taškas).

2 Pusiau atviri intervalai

Dažnai vienas galas įeina, o kitas ne. Toks intervalas vadinamas pusiau atviru: prie įeinančio galo rašomas laužtinis skliaustas, prie neįeinančio — apvalus.

NelygybėIntervalasKuris galas įeina
−2 ≤ x < 5[−2; 5)kairysis (−2)
−2 < x ≤ 5(−2; 5]dešinysis (5)

Pavyzdys. −3 ≤ x < 4 → [−3; 4): skaičius −3 įeina (laužtinis), o 4 neįeina (apvalus).

3 Intervalai su begalybe ∞

Kai nelygybėje tik vienas galas (pvz. x > 3), skaičių eilė tęsiasi be pabaigos. Tada rašome begalybės ženklą: +∞ (į dešinę) arba −∞ (į kairę).

NelygybėIntervalas
x > a(a; +∞)
x ≥ a[a; +∞)
x < a(−∞; a)
x ≤ a(−∞; a]

Pavyzdžiai.
x > 3 → (3; +∞);   x ≤ −1 → (−∞; −1].

Dėmesio. Prie ∞ visada rašomas apvalus skliaustas: begalybė nėra skaičius, jos „pasiekti“ negalima. Todėl niekada nerašome [+∞]. Visa skaičių tiesė: −∞ < x < +∞ → (−∞; +∞).

4 Sveikieji skaičiai intervale

Dažnai reikia nurodyti, kokie sveikieji skaičiai priklauso intervalui: didžiausią, mažiausią arba kiek jų iš viso. Svarbu žiūrėti, ar galas įeina, ar ne.

Pavyzdys 1. Intervale (−3; 5]:
didžiausias sveikasis = 5 (5 įeina, nes laužtinis skliaustas);
mažiausias sveikasis = −2 (−3 neįeina, todėl imame kitą — −2).

Pavyzdys 2. Intervale [−3; 4) sveikieji skaičiai: −3, −2, −1, 0, 1, 2, 3 — iš viso 7 (skaičius 4 neįeina).

Patarimas. Sveikuosius patogu suskaičiuoti nubraižius skaičių tiesę arba tiesiog vardijant iš eilės nuo mažiausio įeinančio iki didžiausio įeinančio.

1 Kas yra paprasta nelygybė

Paprasta nelygybė yra nelygybė, kurios viena pusė yra ax + b, o kita — skaičius. Bendra išraiška: ax + b > c (vietoj > gali būti <, ≤, ≥).

Čia a yra koeficientas prie x, b yra laisvasis narys, o c — skaičius kitoje pusėje.

Spręsti nelygybę reiškia rasti visas x reikšmes, su kuriomis ji virsta teisinga.

Pavyzdžiai.
4x + 12 > 16 — čia a = 4, b = 12, c = 16.
−5x − 2 < 3 — čia a = −5, b = −2, c = 3.
18 + 4x < −18 — laisvasis narys parašytas priekyje (b = 18, a = 4).

2 Du sprendimo žingsniai

Paprastą nelygybę ax + b > c sprendžiame dviem žingsniais:

1) perkeliame laisvą narį  →  2) dalijame iš koeficiento prie x

1 žingsnis. Laisvą narį b perkeliame į kitą pusę su priešingu ženklu (lieka tik narys su x).

2 žingsnis. Abi puses dalijame iš koeficiento prie x. Gauname sprendinį x > ….

Pavyzdys. 4x + 12 > 16

4x > 16 − 12  (perkėlėme 12)

4x > 4

x > 1  (dalijome iš 4)  ⇒  (1; +∞)

Pavyzdys. 3x − 7 ≤ −10

3x ≤ −10 + 7  (perkėlėme −7)

3x ≤ −3  ⇒  x ≤ −1  ⇒  (−∞; −1]

3 Kada keičiame ženklą

Svarbiausia taisyklė. Kai abi puses dalijame (arba dauginame) iš neigiamo skaičiaus, nelygybės ženklą keičiame priešingu: < tampa >, ≤ tampa ≥.

Pavyzdys. −4x + 2 > −3

−4x > −3 − 2  ⇒  −4x > −5

x < 54  (dalijome iš −4, ženklas pakito iš > į <)  ⇒  (−∞; 54)

Pavyzdys. −5x − 2 < 3

−5x < 5  ⇒  x > −1  (dalijome iš −5, ženklas pakito)  ⇒  (−1; +∞)

Dėmesio. Ženklą keičiame tik tada, kai dalijame ar dauginame iš neigiamo. Perkeliant narį per nelygybės ženklą — ženklas NEsikeičia, keičiasi tik perkeliamo nario ženklas.

4 Sprendinys: intervalas ir skaičių tiesė

Nelygybės sprendinį užrašome intervalu. Prie begalybės ∞ visada rašomas paprastas skliaustas.

SprendinysIntervalasKraštinis taškas
x > 1(1; +∞)tuščias ○ (1 neįeina)
x ≥ −2[−2; +∞)užpildytas ● (−2 įeina)
x < −9(−∞; −9)tuščias ○ (−9 neįeina)
x ≤ −1(−∞; −1]užpildytas ● (−1 įeina)

Įsimink. Griežtai (<, >) → paprastas skliaustas ir tuščias taškas. Su lygybe (≤, ≥) → laužtinis skliaustas ir užpildytas taškas.

Pavyzdys. −8 ≤ 11x + 14  ⇒  −22 ≤ 11x  ⇒  x ≥ −2  ⇒  [−2; +∞).

Auksinė taisyklė. Pirma perkeliu laisvą narį, tada dalinu iš koeficiento prie x. Jei koeficientas neigiamas (dalinu iš neigiamo) — keičiu nelygybės ženklą priešingu.
